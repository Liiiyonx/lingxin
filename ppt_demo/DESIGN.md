# 聆心 PPT — Design

## 画布
- 16:9 标准,1280×720px

## 配色(4 色上限,全部 hex)
- 背景: `#0B0B12`(近黑,略带蓝紫)
- 主色: `#A855F7`(紫,强调 / 数字 / 标题)
- 渐变辅色: `#7C3AED → #EC4899`(紫粉渐变,仅用于关键大字)
- 文本主: `#F5F5F7`(米白,正文)
- 文本次: `#9CA3AF`(灰,辅助说明)
- 警示: `#EF4444`(红,只在"风险"词出现)

> 不引入第 5 种色。所有彩色卡片/线框都用上述组合。

## 字体
- 中文: `"PingFang SC", "Microsoft YaHei"`
- 数字/英文: `"Inter", "Helvetica Neue"`
- 标题: 96–120px(hero 大数字)
- 正文: 18–28px

## 母版三区
- A 标题块: 0–120px(顶部留空,大数字悬空)
- B 内容区: 120–660px
- C 页脚条: 660–720px,右下页码 `NN / TOTAL`

## 风格基调
参考用户提供的视频截图:
- 大留黑 + 单色紫粉高亮
- 巨型数字 (96px+) 作为视觉锚点
- 左侧文字块 + 右侧卡片/示意图的版式
- 章节分隔页:超大数字"01/02/03…" + 中英双标签
