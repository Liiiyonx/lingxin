## 3. M0：本地实测声网视频通话（前置，必须过）

**目的**：确认声网这半真的能用，别上云后才发现视频打不通。

1. **确认声网鉴权模式**：
   - 打开 [声网控制台](https://console.agora.io/) → 项目 → 「App 证书」：
     - 若想最快跑通：**关闭证书鉴权**（token 留空即可）
     - 若已开证书：用控制台「Token 生成工具」填 channel 名生成临时 token，临时填进 `.env` 的 `AGORA_TOKEN`
2. **本地起服务**：`python app.py`（确保 `.env` 里 `AGORA_APP_ID` 已填）
3. **双开测试**：
   - 浏览器 A（普通模式）登录学生 `20240001 / 123456`
   - 浏览器 B（无痕模式）登录老师 `zhangwei / counsel123`
   - 学生选中张伟老师 → 点「📹视频」→ 老师端弹出 → 接听
4. **断言**：视频画面互通、老师端实时情绪（面部+语音+融合）启动、挂断后生成情绪总结并回写学生风险。
5. ⚠️ **单点登录注意**：两个浏览器必须是**不同账号**，否则后登录会被 409 拒绝（这正是单点登录的功能）。

> 若 M0 视频打不通，先别急着上云，回本计划书 [风险与排查](#8-风险与排查)。

## 4. M1：代码适配（上云前必改）

### 4.1 CORS / WebSocket origin 改为可配置

现在 [app.py:43-46](app.py#L43-L46) 硬编码 localhost，上云后会被拦。改为从环境变量读取：

```python
import os
_allowed = [o.strip() for o in os.getenv(
    "ALLOWED_ORIGINS",
    "http://localhost:5000,http://127.0.0.1:5000"
).split(",") if o.strip()]

CORS(app, resources={r"/api/*": {"origins": _allowed}})
socketio = SocketIO(app, cors_allowed_origins=_allowed, async_mode='threading')
```

`.env` 里部署时写：
```env
ALLOWED_ORIGINS=https://你的域名,http://你的域名
# 用 IP 直连阶段则写：ALLOWED_ORIGINS=http://服务器公网IP:5000
```

### 4.2 强随机 SECRET_KEY

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

把输出写入 `.env` 的 `SECRET_KEY`，替换现在的弱占位值。**公网前必做**，否则别人可伪造登录令牌。

### 4.3 生产启动：gunicorn

当前 `app.py` 用 Flask 自带 dev server（`app.socketio.run`），生产要用 gunicorn：

```bash
pip install gunicorn
# async_mode='threading' 下用 sync worker + 多线程（最省事）
gunicorn -w 1 --threads 50 -b 127.0.0.1:5000 app:app
```

> 说明：项目 Socket.IO 是 `async_mode='threading'`，用 gunicorn 的 threaded sync worker 最兼容、改动最小；不要用 `-w 4` 多进程（Socket.IO 内存状态不共享，会导致跨进程消息丢失）。

### 4.4 声网鉴权决策（二选一）

| 模式 | 做法 | 适用 |
|---|---|---|
| 无鉴权 | 声网控制台关证书，`AGORA_TOKEN` 留空 | **比赛演示首选**，零后端改动 |
| 有鉴权 | 后端加 token 生成接口（App 证书 HMAC） | 正式长期公开，防盗用 |

本计划书默认走**无鉴权**（演示够用）。若需要鉴权，见 [附录 A](#附录-a声网-token-生成接口)。

### 4.5 服务器形态决策：完整版 vs 精简版

| 形态 | 依赖 | 服务器 | 说明 |
|---|---|---|---|
| **完整版（推荐）** | 全量 requirements.txt（含 torch/transformers/ultralytics） | 2核4G | 省心、所有情绪功能可用，约 298 元/年 |
| 精简版 | 裁掉本地重模型依赖 | 2核2G | 便宜（约 38~99 元/年），但需确认 core 模块 import 是懒加载，且语音/人脸情绪降级为云 LLM |

> 本计划书默认**完整版 2核4G**（比赛要演示情绪分析，别为省钱牺牲功能）。

## 6. M3：部署

### 6.1 安装 Python 与依赖

```bash
apt install -y python3.10 python3.10-venv python3-pip build-essential
# 若系统默认 python3 非 3.10，用 python3.10 显式创建
python3.10 -m venv venv
source venv/bin/activate
pip install -U pip
# 国内镜像加速（torch 等大包必需）
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
pip install gunicorn -i https://mirrors.aliyun.com/pypi/simple/
```

### 6.2 上传代码

```bash
# 方式一：git（推荐，需先把代码推到 GitHub/Gitee 私有仓库）
git clone <你的仓库地址> /opt/lingxin && cd /opt/lingxin

# 方式二：本地打包 scp 上传
scp -r . root@服务器IP:/opt/lingxin/
```

### 6.3 配置 .env（生产）

在服务器 `/opt/lingxin/.env` 写入（**不要提交 git**）：

```env
SECRET_KEY=上一步生成的48位强随机串
DASHSCOPE_API_KEY=你的通义千问key
AGORA_APP_ID=你的声网AppID
AGORA_TOKEN=
ALLOWED_ORIGINS=http://服务器公网IP
DEBUG=false
PORT=5000
HOST=0.0.0.0
```

### 6.4 初始化数据库与演示数据

```bash
cd /opt/lingxin
python -c "from core.database import DatabaseManager; DatabaseManager().init_db()"
python seed_v31.py          # 生成演示数据（600学生+账号）
python scripts/verify_test_accounts.py
# 可选：重建知识库索引
python tools/reindex_kb.py
```

> 数据库 `data/*.db`、模型文件在 `.gitignore` 里，所以必须重新生成，别指望 git 上传。

### 6.5 systemd 守护进程（开机自启 + 崩溃重启）

新建 `/etc/systemd/system/lingxin.service`：

```ini
[Unit]
Description=Lingxin Campus Mind Platform
After=network.target

[Service]
User=root
WorkingDirectory=/opt/lingxin
EnvironmentFile=/opt/lingxin/.env
ExecStart=/opt/lingxin/venv/bin/gunicorn -w 1 --threads 50 -b 127.0.0.1:5000 app:app
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now lingxin
systemctl status lingxin   # 确认 active (running)
```

### 6.6 nginx 反向代理 + WebSocket

```bash
apt install -y nginx
```

新建 `/etc/nginx/sites-available/lingxin`：

```nginx
server {
    listen 80;
    server_name _;   # 备案后改成你的域名

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket / Socket.IO 升级头（关键，缺了实时功能全挂）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 3600s;
    }
}
```

```bash
ln -s /etc/nginx/sites-available/lingxin /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

此时用 `http://服务器公网IP` 即可访问（免备案、无需域名）。

### 6.7 HTTPS（需域名，备案后做）

备案通过、域名解析到服务器后：

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
```

> 摄像头/麦克风要求 HTTPS，所以**视频通话必须走 HTTPS**；文本功能 HTTP 也能用。

## 8. 风险与排查

| 问题 | 原因 | 排查 |
|---|---|---|
| 视频 join 失败 | 声网鉴权 / token / AppID 错 | 控制台关证书鉴权，或填对临时 token |
| WebSocket 连不上（聊天/在线状态挂） | CORS origin 没改，或 nginx 缺升级头 | 查 `.env` 的 `ALLOWED_ORIGINS` + nginx `Upgrade` 头 |
| 摄像头被浏览器禁用 | 不是 HTTPS | 用域名 + certbot 上 HTTPS |
| 登录后账号被占用无法登出释放 | 单点登录会话在内存 | `systemctl restart lingxin` 强制释放 |
| torch 安装失败/超时 | 镜像/磁盘不够 | 用阿里云镜像；2核4G 磁盘建议 ≥40G |
| 跨网视频仍不通 | 声网未真正生效 | 确认前端用的是声网 `publish/subscribe`，非旧 `RTCPeerConnection` |

## 附录 B：精简版依赖裁剪（可选，省钱）

若要用 2核2G 精简版，需在 `requirements.txt` 移除 `torch/transformers/ultralytics/opencv-python-headless`，并确认 `core/yolo_emotion.py`、`core/speech_emotion.py` 等的 import 为**函数内懒加载**（否则启动即崩）。语音/人脸情绪会自动降级为「声学特征 + LLM」。**不熟悉依赖拓扑就不要裁，直接用完整版。**
