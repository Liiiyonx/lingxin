# 聆心 · 部署指南

## 1. 环境要求

- Python 3.10+（推荐 3.10）
- 有效 DashScope API Key（通义千问）
- （可选）联网环境，用于首次下载情绪模型

## 2. 安装步骤

```bash
# 1. 创建虚拟环境（推荐）
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

# 2. 安装基础依赖
pip install -r requirements.txt

# 3. 安装真实情绪模型依赖（可选，用于语音情绪识别升级）
pip install funasr modelscope
```

## 3. 配置环境变量

复制 `.env.example` 为 `.env`，填写：

```ini
SECRET_KEY=请替换为至少32位随机字符串
DASHSCOPE_API_KEY=sk-你的通义千问密钥
PORT=5000
DEBUG=false
```

> ⚠️ 若你的 `.env` 已包含真实 API Key 且曾被分享/提交，请前往阿里云控制台**轮换密钥**。

## 4. 初始化数据库与知识库

```bash
# 数据库建表（含增量迁移）
python -c "from core.database import DatabaseManager; DatabaseManager().init_db()"
python tools/migrate_db.py

# 生成演示数据（首次运行）
python seed_v31.py

# 重建知识库索引（docs/ 目录下的文档）
python tools/reindex_kb.py
```

## 5. 启动

```bash
python app.py
# 或 Windows 双击 启动平台.bat
```

访问 http://localhost:5000

## 6. 首次运行模型下载说明

- **语音情绪模型**（emotion2vec）：首次调用语音分析时自动下载（约数百 MB），需联网。下载失败时自动降级为「声学特征 + LLM」模式，不影响使用。
- **人脸检测模型**（yolov8n-face）：首次人脸识别时由 ultralytics 自动下载（约 6MB）。
- **人脸情绪模型**（transformers FER）：首次人脸识别时由 HuggingFace 自动下载。

## 7. 测试与评测

```bash
# 全接口冒烟测试
python tests/test_routes.py

# 情绪识别评测（输出 docs/评测报告.md）
python tools/benchmark_emotion.py                      # 文本模式（内置样例）
python tools/benchmark_emotion.py --mode audio --manifest audio_labels.json
```

## 8. 常见问题

| 问题 | 处理 |
|------|------|
| RAG 初始化报错 `'_type'` | 旧版 chromadb 索引不兼容，已自动重建；或手动删除 `data/chroma_db` 后运行 `tools/reindex_kb.py` |
| 语音情绪分析返回 `_source: llm` | 说明 emotion2vec 未安装或加载失败，正走降级路径；安装 `funasr modelscope` 即可升级 |
| 人脸情绪返回「未知」 | FER 模型未下载成功，首次需联网 |
