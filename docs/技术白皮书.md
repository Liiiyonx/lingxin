# 聆心 · 技术白皮书

> 高校辅导员 AI 减负与心理预警一体化平台 · v3.2

---

## 1. 项目概述

**聆心** 面向高校辅导员与学工部门，解决两个核心问题：

1. **文书减负**：谈心谈话记录、主题班会策划、行政公文、请假审批等重复性文书工作，借助大语言模型自动生成符合学校规范的成果。
2. **心理预警**：通过「语音情绪识别 + 人脸表情识别 + 文本情绪识别 + 心理测评量表」多模态手段，主动识别学生心理风险，辅助辅导员及早干预。

**价值主张**：让辅导员把时间从「写材料」还给「见学生」。

### 3.1 情绪识别的「名实对应」

本项目情绪识别采用**多级策略**，并在每次识别结果中通过 `_source` 字段如实标注来源：

1. **真实模型推理**（`emotion2vec`）：语音情绪识别优先走开源语音情绪模型，本地推理、无需上传音频。
2. **规则预判**（`rule`）：静音/低能量音频直接判为正常，跳过模型调用，节省成本。
3. **LLM 研判**（`llm`）：真实模型不可用时，降级为「声学特征 + 大模型研判」。

**如实说明**：情绪识别属于「辅助研判」而非「医学诊断」，系统定位为辅导员工作的预警辅助工具。

## 4. 数据模型

共 14 张表，核心实体关系：

- **用户与权限**：`users`（三级角色）、`students`（学生，含辅导员归属）
- **业务数据**：`conversation_records`（谈心记录）、`emotion_logs`（情绪日志）、`alert_logs`（预警，含确认/解决审计字段）、`student_profiles`（学生档案）、`emotion_trackers`（情绪追踪）
- **协同功能**：`messages`（师生 IM）、`appointments`（预约）、`reminders`（跟进提醒）、`todos`（待办）、`assessment_results`（测评结果）
- **安全审计**：`system_logs`（操作日志）、`token_blacklist`（登出令牌）

## 5. 安全设计

| 措施 | 说明 |
|------|------|
| 密码安全 | pbkdf2:sha256 加盐哈希（werkzeug） |
| 认证 | 签名令牌（itsdangerous）+ 令牌黑名单（登出即失效） |
| 权限控制 | 路由级 RBAC 装饰器 + 数据级隔离（辅导员仅见本人学生） |
| 登录防护 | 基于 IP 的内存级登录限流（5 分钟窗口） |
| 请求限制 | 上传大小上限 100MB、文件类型白名单 |
| 配置安全 | SECRET_KEY 生产环境强制校验；`.env` 不入库（.gitignore） |
| 隐私 | 语音情绪模型本地推理，音频数据不离开服务器 |

**已知待改进**：文本/谈心记录等需经云 API 处理，完整「数据不出校」需引入本地化 LLM 部署（见第 7 节路线图）。

## 7. 局限性与路线图

**当前局限（如实陈述）**：

1. 语音情绪识别仅覆盖 emotion2vec 的 7 类基本情绪（愤怒/厌恶/恐惧/高兴/正常/悲伤/惊讶），与系统 12 类中文标签存在映射损失。
2. 人脸情绪识别依赖模型下载（首次使用需联网），模型不可用时如实返回「未知」。
3. 微表情/姿态融合为规则加权（非端到端模型），需真实标注数据验证。
4. 暂无真实部署与试点验证数据。

**路线图**：

1. 接入 SenseVoice 做「语音转写 + 情绪」双输出，补齐中文情绪细粒度。
2. 引入本地化 LLM（如 Qwen 本地部署）实现真正的「数据不出校」。
3. 采集真实标注样本，完成情绪识别的第三方评测。
4. 与一所高校合作试点，验证减负与预警效果。
