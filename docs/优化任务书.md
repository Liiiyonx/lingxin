## 二、P0 紧急修复（必须先做）

### Bug 1：辅导员工作台接口崩溃

**根因**（已定位）：[core/database.py](core/database.py) 的 `Todo` 模型加了 `student_id` 外键，但**漏加了 `student` relationship**。`get_today_workplan` 里访问 `t.student.name` 时抛 `'Todo' object has no attribute 'student'`，导致 `/workplan/today` 接口整体失败，返回空数据。

**修复**（一行）：
```python
# core/database.py，Todo 模型里补上 relationship
student = relationship("Student", foreign_keys=[student_id])
```

**验收**：辅导员登录后工作台显示「学生总数 50、高风险/中风险正确、待办列表、日历事件」。

### Bug 2：学生端测评/预约/个人中心空白

**根因**（已定位）：[templates/partials/student_pages.html](templates/partials/student_pages.html) 第 32 行 `<div v-if="page==='studentChat'">` **缺少一个闭合 `</div>`**，导致后续 `studentAppointment`、`studentAssessment`、`studentProfile` 三个页面被嵌套进 `studentChat` 的 `v-if` 里。切换到这三个页面时，外层 `v-if="page==='studentChat'"` 为 false，内容整体不渲染。

**修复**：在第 57 行（`</div>` 之后、第 59 行「学生预约」注释之前）补一个闭合：
```html
                </div>
```

**验收**：学生登录后，「心理测评」「预约咨询」「个人中心」三个页面都能正常显示题目/表单/个人信息。

## 三、P1 次要问题

### P1-1 学生管理分页
- **现状**：`students` 页只显示前 20 条，「上一页/下一页」按钮 disabled。
- **实现**：前端 `loadStudents` 请求带 `page` 参数，后端已支持分页（`get_students` 返回 `total`）；前端加 `studentPage` 状态 + 上一页/下一页点击事件，按钮绑定 `:disabled="studentPage<=1"` / `:disabled="studentPage*per_page>=total"`。

### P1-2 管理员看板文案
- **现状**：「监测学生总数 2001」实际是情绪日志条数。
- **实现**：把 [staff_core.html](templates/partials/staff_core.html) 里的标签改为「情绪样本总数」，或后端 `emotion_statistics` 返回真实的 `student_count` 单独展示。

### P1-3 清理测试脏数据
- **现状**：管理员预警列表有 100 条「测试学生/实时视频通话」预警，来自冒烟/闭环测试。
- **实现**：运行 `python seed_v31.py` 重新生成干净的确定性数据；之后提交一个 `scripts/clean_test_data.py`，或让闭环测试在 `finally` 里清理（已有部分清理）。
